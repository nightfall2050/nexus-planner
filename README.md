# NEXUS Planner

A privacy-first personal planner and smart calendar.

## Project status

Initial setup. The first release will be a static, client-side application hosted with GitHub Pages.

## Privacy principles

- Personal events stay in the user's browser by default.
- Never commit personal calendar data, backups, credentials, or API keys.
- AI-generated changes must be validated and previewed before applying.
- Deleting or changing recurring events must clearly specify the scope.

## Development principles

- Develop on feature branches and review changes before merging to `main`.
- Run build and behavior checks before deployment.
- Keep dependencies minimal and review licenses before reusing third-party code.
- Export/import backups should be user-controlled.

## Planned first release

- Responsive month, week, and day views
- Tasks, completion state, recurring schedules, and per-date exceptions
- Natural-language change proposals with confirmation
- Local persistence, JSON backup/restore, undo, and browser notifications
- Automated checks and GitHub Pages deployment
